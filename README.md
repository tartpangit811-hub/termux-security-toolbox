# Termux Security Toolbox

A collection of security, networking, and system administration tools for Linux and Termux users.

## Overview

Termux Security Toolbox is a simple toolkit designed to help Linux and Termux users perform common security checks, generate strong passwords, view system information, diagnose network issues, and analyze storage usage.

This project is intended for:

* Linux Beginners
* Termux Users
* Students
* IT Support Personnel
* Network Technicians
* System Administrators

## Features

### Password Generator

Generate strong and secure passwords with customizable length and complexity.

### Security Scanner

Perform basic security checks such as:

* Open port detection
* Service inspection
* Permission checks
* Security reporting

### System Information

Display important system details including:

* Operating system
* CPU information
* Memory usage
* Storage information

### Network Diagnostics

Troubleshoot network connectivity problems with tools such as:

* Ping tests
* DNS checks
* Gateway verification
* Network information

### Storage Analyzer

Monitor storage usage and identify areas consuming disk space.
